# Crypto Screener

Crypto screener for Delta Exchange India.

## Structure

- `backend/` — Node.js + Express + TypeScript API, wraps Delta Exchange India API
- `frontend/` — React + Vite + TypeScript + Tailwind CSS + Hugeicons dashboard

## Getting Started

### Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```
